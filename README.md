# 👓 Ótica Arte

Site institucional desenvolvido para a Ótica Arte, com foco na apresentação de produtos, serviços e contato com clientes.

---

## 🚀 Tecnologias Utilizadas

- React
- JavaScript
- CSS3
- HTML5

---

## 📌 Objetivo do Projeto

O projeto foi desenvolvido com o objetivo de:

- Apresentar óculos de grau, solares e armações
- Divulgar os serviços da ótica
- Facilitar o contato com clientes
- Melhorar a presença digital da empresa

---

## 🖥️ Funcionalidades

- Página inicial moderna e responsiva
- Seção de produtos
- Seção "Sobre nós"
- Formulário de contato
- Layout adaptado para dispositivos móveis

## ⚙️ Como Rodar o Projeto

Clone o repositório:

git clone https://github.com/rodrigocav/otica-arte.git

Acesse a pasta:

cd otica-arte

Instale as dependências:

npm install

Execute o projeto:

npm start

O projeto será iniciado em:

http://localhost:3000
